# جمع سجلات الدراسات العليا

دفعة 25 أكتوبر 2026. جميع الملفات التي تحوي أشخاصًا أو محاضر في `private-data/harvest-20261025/` محليًا، وهي مستثناة من Git وحزمة Netlify. المسار العام يحوي الشيفرة والمنهج والأعداد الإجمالية فقط.

## التغطية

- كشوف KPI: 2465 مشاهدة مصدرية لطلاب الدراسات العليا، أصبحت 1801 قيدًا فريدًا في عشرة برامج. أُزيلت 664 مشاهدة مكررة مع حفظ تاريخها ومصدرها. هوية القيد رقم جامعي + برنامج + درجة، وليست الاسم.
- الرسائل: 509 صفوف من الشيت الحي و467 من المستودع. نتجت 520 هوية محتوى بعد إزالة 456 تكرارًا. معرف الصف في الشيت ليس معرف الرسالة في المستودع؛ أُعيد ترقيمها بين المصدرين. الهوية هنا الدرجة + البرنامج + الاسم المطبع + العنوان المطبع، وتستخدم لجمع مشاهدات الرسالة فقط، ولا تثبت هوية الطالب.
- المحاضر: حُفظ 151 PDF ببصماتها، و1394 صفحة. النص المضمن قابل للبحث في 193 صفحة؛ فُحصت ضوئيًا 410 صفحات ضعيفة النص في 73 محضرًا لها موضوعات دراسات عليا، وكان النص الناتج صالحًا للبحث في 408 منها. المجموع المفحوص للربط 601 صفحة؛ بقية الصفحات ليست مدققة ضوئيًا في هذه الدفعة.
- الروابط المعتمدة: 13 طالبًا برسائلهم؛ 38 طالبًا بمحاضر عبر 45 علاقة طالب/محضر. منها 24 علاقة جرى نسخها من صفحات عوينت بصريًا، و21 علاقة من نص أصلي يذكر الرقم والاسم كاملًا. أضيفت ستة إثباتات عناوين من المحاضر غير المحسومة في سجل الرسائل السابق؛ لا تعد هذه ست رسائل جديدة مستقلة دون مراجعة النسخ.
- مستودع الخطط يوفر دليل البرامج والسياق. لا تنقل مقررات الخطة إلى الطالب بوصفها مقررات اجتازها. بيانات الاستطلاعات والدراسة الذاتية مجمعة أو مؤسسية ولا تُنسب إلى أشخاص.

## قواعد الاعتماد

1. تثبيت commit وبصمة Git وSHA-256 ومسار المصدر لكل ملف. الشيت نسخة مؤرخة بنطاقها وتبويبها وبصمتها.
2. الرقم الجامعي الصريح مع البرنامج والدرجة وقرائن الاسم في الوثيقة. ربط الرسالة يتطلب عنوانًا مؤيدًا أيضًا. التطابق بالاسم وحده يبقى مرشحًا.
3. النص الضوئي وسيلة بحث؛ لا تنشئ أرقامه قيد طالب جديدًا آليًا. الاعتماد البصري لعلاقة بعينها وليس تفويضًا لكل الصفحة. اختلاف جوهري في اسم العائلة يوقف العلاقة ولو تطابق الرقم.
4. الإشراف المسجل باسم فقط يبقى كما ورد، بلا تخمين معرف وظيفي. المعرفات الرقمية للموظفين تربط مباشرة بسجل الأعضاء مع إثبات صفه وسنته.
5. اختلاف حالة القيد في السنة نفسها ينتج حالة «غير موثق» وقائمة تعارض، لا ترجيحًا صامتًا. تواريخ الرصد والجمع مستقلة عن تاريخ استخراج الكشف الذي لم يثبت.
6. التواريخ الهجرية نصوص مصدرية مع تقويمها، دون تحويل آلي أو إدراجها كتاريخ ميلادي. لا تستنتج التخرج من إنجاز الرسالة أو الغياب. لا تخمن مقياس المعدل أو فصل القبول.
7. فهرس `research_evidence` إحالة مصدرية؛ إرفاقه لا يعني معاينة الروابط الخارجية الواردة فيه. مطابقة معرفه مقيدة بتبويب الرسائل نفسه ويجب أن يؤيدها العنوان.

## المخرجات الخاصة

| الملف | الغرض |
| --- | --- |
| `output/grad-students-import.grad.json` | استيراد القيود مع العلاقات المعتمدة والمصادر إلى مدار |
| `output/students-master.json` | السجل الموحد ومشاهداته التاريخية |
| `output/theses-master.json` | جميع الرسائل ومشاهداتها، بما فيها غير المرتبطة بطالب |
| `output/council-links.json` | علاقات المحاضر المعتمدة وطريقة قراءتها |
| `output/review-queue.json` | المرشحات والتعارضات؛ لا تستورد كحقائق |
| `output/quality-summary.json` | أعداد الدفعة وحدودها |
| `sources/` | نسخ المصدر والفهارس وبصمات الملفات |
| `visual-review.json` | العلاقات المنسوخة من الصفحات وفهرس تعارض الهوية |
| `quality-checks.ipynb` | تحقق قابل للإعادة من الهوية والأدلة والأعداد |

استيراد JSON يحفظ العلاقات، أما Excel/CSV فاستيرادهما للحقول المسطحة فقط. لا يحتوي ملف الاستيراد على جميع الرسائل غير المرتبطة؛ تحفظ هذه في السجل الخاص وقائمة المراجعة. لا تصف كل القيود بأنها حديثة أو كاملة.

## التشغيل

يتطلب الجمع GitHub CLI موصولًا بالحساب المصرح، وPython، وPoppler، وTesseract مع `ara+eng` للقراءة الضوئية. الشيت يُقرأ عبر Google Drive المتصل وتُحفظ النسخة المحدودة بنطاقها في `sources/google-sheets/`؛ لا تكتب هذه الأدوات في المصادر.

```sh
python3 scripts/collect_sources.py --output private-data/harvest-YYYYMMDD/sources
python3 scripts/collect_councils.py --sources private-data/harvest-YYYYMMDD/sources
python3 scripts/index_councils.py --sources private-data/harvest-YYYYMMDD/sources
python3 scripts/ocr_councils.py --sources private-data/harvest-YYYYMMDD/sources
python3 scripts/harvest_graduates.py --root private-data/harvest-YYYYMMDD
node scripts/validate_harvest.mjs private-data/harvest-YYYYMMDD/output/grad-students-import.grad.json
python3 -m unittest discover -s tests -p 'test_*.py'
```

لا تُعد تشغيل الجمع على المجلد نفسه لاستبدال نسخة قديمة دون حفظها؛ أنشئ دفعة جديدة بتاريخها. `review_candidates.py --root …` ينشئ قائمة خاصة لمساعدة فحص الصفحات، ولا يعتمد المرشحات.

## التوافق مع ملفات مدار السابقة

بقي `schemaVersion=1` لأن التغيير إضافي. عند قراءة الملفات القديمة تضاف `evidence=[]` و`researchRecords=[]` و`asOfAcademicYear=''` آليًا؛ لا تتغير المعرفات أو قيم المقاييس القديمة. المقاييس الجديدة غير المتاحة `null`. أخذ نسخة JSON قبل استيراد تحديث يحفظ إمكانية الرجوع. اختبارات التطبيق تتحقق من بقاء الأدلة والتواريخ الأصلية خلال JSON/Excel والطباعة، ومن رفض مرجع دليل غير موجود.
