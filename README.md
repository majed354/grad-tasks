# مدار | بيانات طلاب الدراسات العليا

مساحة عربية لجميع برامج الدراسات العليا بكلية الشريعة والأنظمة بجامعة الطائف. تجمع بيانات الطالب ومساره ورسالتَه وإشرافَه وقراراته ومهامه وروابط وثائقه في ملف واحد.

هذا هو المستودع الوحيد للمشروع: [majed354/grad-tasks](https://github.com/majed354/grad-tasks).
الموقع المنشور على Netlify: [grad-tasks.netlify.app](https://grad-tasks.netlify.app/).
المجلد المحلي المعتمد: `/Users/majd/Desktop/claudeMe/مهام الدراسات العليا`.

## ما يعمل في الإصدار الأول

- سجل طلاب بالبحث بالاسم والرقم الجامعي والمشرف وعنوان الرسالة، وتصفية البرنامج والدرجة والحالة والمرحلة.
- إضافة وتعديل ملف الطالب: القبول والدفعة والتواصل والمعدل والساعات والرسالة والإشراف والتواريخ والمصدر.
- إضافة وتعديل المقررات والمهام والقرارات وروابط الوثائق والمتابعات، وإنجاز المهام ومراجعة التأخر.
- استيراد XLSX (الورقة الأولى)، وCSV، ونسخ JSON؛ مطابقة أعمدة ومعاينة وتحقق من الأخطاء قبل الحفظ.
- اختيار الطلاب والحقول وتصدير Excel حقيقي بعشر أوراق تشمل الرسائل والمصادر والرصد الأكاديمي، أو CSV، أو نسخة JSON كاملة قابلة لإعادة الاستيراد.
- معاينة ملف طالب أو عدة ملفات كاملة مع روابطها قبل الطباعة، والحفظ كـPDF من نافذة الطباعة.
- تجربة افتراضية مستقلة لا تمس البيانات المحفوظة، وتوثيق مصادر كل طالب وروابط الرسالة والإشراف والمحاضر.
- دليل مبدئي لستة برامج ماجستير وأربعة دكتوراه وفق README مستودع الخطط (25 أكتوبر 2026). يسمح الإدخال بإضافة أسماء برامج أخرى. تعيين الأقسام اقتراح قابل للتعديل وليس حصرًا رسميًا مستقلاً.

## العرض بحسب السنوات

السنة الافتراضية **1448هـ**. تتغير القوائم والأرقام والتقارير مع السنة والفصل المحددين. يختار العرض الفصل الثاني عند توفره، وإلا الأول، ويبقى الصيفي اختيارًا مستقلًا. لكل فصل تستخدم أحدث نسخة استخراج متاحة دون حمل طلاب غائبين من نسخ أقدم. خيار «جميع السنوات» يعرض قيدًا واحدًا لكل رقم جامعي وبرنامج ودرجة مع تاريخه الكامل. البيانات الغائبة تظهر غير متاحة.

تفرق البطاقات بين جميع القيود المرصودة والمنتظمين. لقطة 481 للسنة 1448 من تصدير 7 أكتوبر 2026 أولية، ولا تمثل تعداد نهاية السنة. الإشراف والرسائل مصادر تاريخية مستقلة وتظهر مع مواضع أدلتها، ولا تنسب تلقائيًا إلى السنة المختارة. ملفات الفرد التي لم يوثق لها رصد فصلي تبقى في السجل العام.

## أين تُحفظ البيانات الآن؟

هذا إصدار تأسيسي **بالحفظ المحلي**. يعمل الموقع على Netlify، لكن البيانات المدخلة تحفظ في IndexedDB في متصفح المستخدم. لا يوجد خادم بيانات أو تسجيل دخول أو مزامنة بين الأجهزة في هذا الإصدار. البيانات الفعلية لا تضاف إلى GitHub أو حزمة النشر. جميع الأمثلة المرفقة افتراضية.

حذف بيانات المتصفح أو تغيير الجهاز أو عنوان الموقع يفصل المستخدم عن سجلاته السابقة. استخدم نسخة JSON قبل الانتقال أو التحديثات المهمة. يمكن لمن يستطيع الوصول إلى الجهاز والمتصفح الوصول إلى المخزن؛ الحفظ المحلي ليس نظام صلاحيات مؤسسيًا ولا تشفيرًا للبيانات.

المرفقات حاليًا **روابط وثائق**، وليس رفع ملفات أو نسخًا من ملفات Drive. يحتفظ المصدر الأصلي بصلاحيات الملف. خريطة المصادر لا تعني تشغيل مزامنة أو استيراد بيانات تلك المستودعات.

## النشر المستمر على Netlify

- مستودع GitHub: `majed354/grad-tasks`، الفرع `main`.
- أمر البناء على Netlify `npm test && npm run build`، ومجلد النشر `dist`، محددان في `netlify.toml`.
- الخطوط محلية داخل الحزمة؛ لا توجد تحليلات أو اتصالات تلقائية بمصادر خارجية.
- `.netlify/` مستثنى من Git، و`private-data/` للملفات المحلية فقط ومستثنى أيضًا.
- لا تستخدم نشر المجلد الجذري؛ الحزمة المنشورة هي `dist` فقط.
- يحوي الإعداد CSP لمنع النصوص والاتصالات الخارجية، ومنع تضمين الموقع داخل إطار، ومنع فهرسة محركات البحث. هذه رؤوس متصفح وليست مصادقة مستخدمين.

تفاصيل حالة الربط والنشر في [PROJECT_LOG.md](PROJECT_LOG.md).

## إعداد ملف الاستيراد

نزّل القالب الفارغ من «إعدادات المساحة». الحقول المطلوبة في كل صف: `الرقم الجامعي`، `اسم الطالب`، `البرنامج`، `الدرجة` (`ماجستير` أو `دكتوراه`). التواريخ ميلادية بصيغة `YYYY-MM-DD`، ودفعة القبول حقل نصي مستقل مثل `1448`. حوّل صيغ Excel إلى قيم قبل الاستيراد. الحد 64 ميجابايت لنسخ JSON و20 ميجابايت لـExcel/CSV، و20 ألف قيد لكل ملف.

هوية القيد هي الرقم الجامعي + البرنامج + الدرجة، مع معرف داخلي مستقل؛ الاسم ليس مفتاح دمج. القيد المطابق يُتجاوز افتراضيًا. عند تفعيل التحديث في CSV/Excel تستبدل القيم غير الفارغة فقط وتحفظ السجلات المرتبطة. عند تحديث سجل من JSON تُستبدل بياناته وسجلاته المرتبطة كاملة، دون حذف الطلاب خارج الملف. أي خطأ في المعاينة يمنع حفظ الدفعة كلها. استيراد JSON يحفظ الطلاب، ولا يعيد تاريخ العمليات القديم بوصفه عمليات جديدة.

المعدل والساعات قيم مصدرية مسجلة؛ لا يعاد حسابهما من المقررات. مقياس المعدل يقبل قيمة غير موثقة. آخر سنة رصد لا تؤكد الحالة الحالية، ومرحلة الدراسة تقبل «غير موثق». غياب الطالب أو إنجاز رسالته لا يثبت تخرجه. المواعيد المستهدفة مدخلات متابعة وليست مددًا نظامية معتمدة.

## جمع المصادر

نُفذت دفعة جمع محلية من المستودعات والشيت المحدد، مع توثيق الإصدارات والبصمات والصفوف وصفحات المحاضر. الملفات الفعلية وملف الاستيراد وقائمة التعارضات في `private-data/harvest-20261025/` المستثنى من Git. تفاصيل المنهج والتغطية في [دليل الجمع](docs/HARVEST.md). لا توجد مزامنة دورية؛ الاستيراد إلى مساحة المتصفح خطوة مستقلة، ولا تنتقل البيانات إلى بقية الأجهزة.

## بنية المشروع

```text

  Profile.tsx         ملف الطالب والسجلات المرتبطة والطباعة

  DataDialogs.tsx     معاينة الاستيراد وتخصيص التصدير
  model.ts            عقد البيانات والتحقق
  storage.ts          IndexedDB ومنع الكتابة المتعارضة
  io.ts               قراءة الملفات وإنشاء Excel وCSV وJSON
  catalog.ts          البرامج والمراجع
  demo.ts             أمثلة افتراضية فقط
tests/                اختبارات هوية البيانات والدمج والحفظ والتصدير
docs/                 قرارات المشروع ومراحله
private-data/         مصادر محلية مستثناة من Git
```
